# Contributing to QE2AI

Thank you for your interest in contributing to **QE2AI**! 🚀

Our mission is to empower Quality Engineers and SDETs worldwide to transition into AI Engineering through practical, production-grade hands-on projects.

---

## 🛠️ How to Contribute

### 1. Reporting Bugs & Issues
- Check the existing [GitHub Issues](https://github.com/poornaai2026/QE2AI/issues) to ensure your topic hasn't already been addressed.
- If creating a new issue, include:
  - Clear title and description
  - Steps to reproduce
  - Project track number (`01` through `10`)
  - Python version & environment details

### 2. Suggesting Enhancements or New Mini-Projects
- Open a feature request discussion explaining the proposed project, why it's valuable for the QE-to-AI transition, and the suggested tech stack.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create a descriptive feature branch:
   ```bash
   git checkout -b feat/project-improvement
   ```
3. Ensure your Python code is clean, typed, and formatted (`black`, `ruff`, or `flake8` compliant).
4. Verify all tests pass in the relevant project:
   ```bash
   pytest
   ```
5. Commit with clear semantic commit messages:
   ```bash
   git commit -m "feat(track-05): add automated cyclic reflection test"
   ```
6. Push to your fork and submit a Pull Request against `main`.

---

## 📜 Code of Conduct
Be respectful, constructive, and supportive to all learners and contributors.
